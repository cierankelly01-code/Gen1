# Reporting a security issue

Email **info@genexuk.co.uk** with the details and the page or address affected.
Please don't publish the issue before we've had a chance to fix it, and don't access
anyone else's data. We'll acknowledge the report and keep you updated on the fix.

This repository is the public Genex UK website (static pages served by nginx).
The same contact is published at `/.well-known/security.txt`.
