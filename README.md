# Genex UK — website (pitch build v1)

A static, multi-page demo site built to show Genex what their web presence could be. Content is drawn from their current site, their own photos and the quote packs they sent ("AI Quoting Development Files").

## Run it

```bash
python -m http.server 8420 --directory site
```

Then open http://localhost:8420. Pages use root-relative paths (`/assets/...`), so serve the `site` folder as the web root. Opening the files directly won't work.

## Edit it

- **Page content:** `_src/pages/*.html`. Each file starts with a `<!--meta {...} -->` header holding the title, description, path and nav state.
- **Shared header/footer:** `_src/partials/layout.html`. The closing CTA band is in `_src/partials/cta.html`.
- **Rebuild after any edit:** `python build.py` writes the finished pages to the `site/` root.
- **Re-skin:** `assets/css/tokens.css` holds every colour, font size, spacing value and easing.
- **Hero media chain** (`[data-press]` in `_src/pages/index.html`, logic in `assets/js/site.js`):
  1. **Real footage.** Set `data-video="/assets/video/hero.mp4"` (and `data-poster`) on the figure. If the video fails to load, it falls back to 2.
  2. **Real-time 3D die.** `assets/js/press3d.js`, using three.js r160 (MIT licence) vendored in `assets/vendor/`. It loads lazily on desktop (640 px or wider, WebGL2 available, no reduced-motion or data-saver), shows true progressive indexing with every station working on every stroke, and pauses when off-screen.
  3. **SVG strip.** Generated by `strip_svg()` in `build.py`. Used on phones, with reduced motion or JS off, and while 3D loads.
- **Footage brief for Genex:** see the published filming brief (shot list, settings, confidentiality rules).
- **Hosting:** serve with gzip or brotli. `three.module.min.js` is 670 KB raw and about 170 KB compressed, and it only loads on desktop.
- **Screenshot mode:** add `?static` to any URL to disable animations.
- **Deploying:** publish everything in `site/` except `_src/` and `build.py`.

## Design direction: "Drawing Office"

- Paper and graphite, Genex blue for annotation, Genex red **only** for actions.
- Fonts: Archivo (wide display cut) with IBM Plex Mono for spec data.
- The signature moment is the live progressive-die hero. Every ~1.3 s the ram strokes and a station fills (pierce, notch, form, nut, cut-off), then the e-coated part drops out. It pauses on hover, when off-screen and with the Pause button, and shows the finished strip under reduced motion.

## Before going live (production checklist)

1. **Photography.** This is the biggest upgrade available. The current photos are 400–800 px, so they blur on large and retina screens. Shoot tight close-ups of the toolroom, die steel, press line, weld cell and parts in stillages at 2000 px+, then add `srcset`.
2. **RFQ backend.** The form currently runs in demo mode. Set `data-endpoint` on the form to post multipart data to the lead pipeline (the dashboard and AI outreach build plug in here), and send a copy to sales@.
3. **Self-host fonts.** Use subset WOFF2 files and preload the display face. This removes the Google Fonts dependency, which helps both performance and EU GDPR.
4. **Analytics.** `window.track()` is already wired for CTA clicks, RFQ submit/errors and press interactions. Point it at GA4 or Plausible, and add a consent banner only if trackers need one.
5. **Platform.** Decide whether to keep this as a static site (fast, secure, cheap) with a headless CMS, or port it to WordPress for in-house editing.
6. **301 redirects** from the old `?page_id=` URLs to the new pages. Submit `sitemap.xml` in Search Console and Bing Webmaster Tools.
7. **Fix on the current WordPress site:** close the public user-list endpoint (`?rest_route=/wp/v2/users`), which exposes the admin login name.

## Going global (SEO plan)

- **One English site** (`en-GB` plus `x-default` hreflang is already in place). Don't split UK/US versions until commercial terms genuinely differ. Spelling alone doesn't justify it.
- **`/global.html`** targets "UK metal stamping supplier", "press tool maker for export" and similar searches, with answer-first copy, FAQ schema and Incoterms detail.
- **Phase 2: a German landing page** (`/de/`). Their RFQ packs include German part descriptions from BMW/Mini-chain Tier 1s, and the DACH supply chain is a real opportunity. Add `hreflang="de"` only when the page exists.
- **AI search (ChatGPT, Perplexity, Gemini).** `robots.txt` allows AI crawlers, `llms.txt` is published, Organization/FAQ/Service JSON-LD is set, and the copy is evidence-dense (real numbers, op routings).
- **Monthly AI-search check.** Ask each assistant: "UK press tool maker for automotive brackets", "metal pressings supplier West Midlands PPAP", "UK supplier progressive tooling export to US". Log whether Genex is mentioned and cited.
- **US tariff reality.** Stamped steel parts face roughly 25% duty into the US (as of Oct 2026), so lead US conversations with tooling and specialist work, not commodity pressings.

## Independent design review log

Each round was scored by a fresh reviewer briefed as "a competitor agency built this, find what's wrong" (rubric of 10 categories × 10 points, pass mark 85).

| Round | Score | Main changes after the round |
|---|---|---|
| 1 | 62 | Buyer-checklist strip, hand-off diagram, mobile tap-to-step, RFQ reassurance, AA type sizes |
| 2 | 69 | **Rebuilt the hero around the live die strip**, proof moved to section 2, compact RFQ, mobile sticky CTA |
| 3 | 62 (new reviewer, harsher) | Readable strip, "the call we made" notes, seals removed, industries re-weighted, tighter rhythm |
| 4 | 67 | One lead-time story, Pause button, red reserved for action, file-format consistency |

**The 85 pass mark has not been reached.** The remaining gaps are mostly:

- missing real assets and data: photography, press list, certificates, IATF status;
- production work: self-hosted fonts, the form backend;
- a below-the-fold layout that reviewers still find template-like.
